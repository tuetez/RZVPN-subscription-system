RZVPN Subscription System
==========================

راه‌اندازی در Termux:
1) unzip RZVPN-subscription-system.zip
2) cd RZVPN-subscription-system
3) npm install
4) npm start

سپس در مرورگر:
http://localhost:3000

امکانات:
- هر محصول دکمه «ساخت لینک اشتراک» دارد.
- برای هر درخواست یک توکن اختصاصی ساخته می‌شود.
- لینک عمومی /sub/TOKEN ساخته می‌شود.
- /sub/TOKEN/raw برای خروجی خام اشتراک آماده شده است.
- محصولات مرتبط در هر کارت نمایش داده می‌شوند.
- برای اشتراک واقعی باید کانفیگ‌های واقعی سرورها (VLESS/VMess/Trojan/WireGuard و...) به backend اضافه شوند.
- لینک محلی localhost از اینترنت قابل دسترسی نیست؛ برای لینک عمومی بدون VPN باید همین پروژه روی یک سرور/هاست عمومی با دامنه یا آدرس عمومی اجرا شود.
